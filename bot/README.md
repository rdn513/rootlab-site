# Бот @rootlab_help_bot и приём заявок

Один контейнер делает три вещи:

1. **Ведёт воронки в Telegram.** Каждая кнопка сайта открывает бота со своей меткой `?start=…`. По метке бот выбирает сценарий, задаёт 3–5 вопросов кнопками, берёт согласие на обработку персональных данных и отправляет заявку в чат команды.
2. **Принимает форму сайта.** Обрабатывает `POST https://api.root-lab.ru/lead` и присылает карточку в тот же чат.
3. **Ведёт переписку и статистику.** Ответ в чате команды на карточку через «Ответить» (reply) бот пересылает клиенту. Новые сообщения клиента приходят обратно в чат. Команда `/stats` показывает конверсию воронок.

## Воронки

| Воронка | Кнопки сайта | Что спрашиваем |
| --- | --- | --- |
| 🔎 Экспресс-аудит | первый экран, «Цены → аудит», финальный блок, `/audit` | кто вы, сайт, сколько серверов, где хостинг, что беспокоит |
| 🩺 Техосмотр | «Техосмотр — 12 000 ₽» везде | сайт, платформа (для Tilda честно говорим, что смысла мало), что беспокоит |
| 🔴 Аварийная помощь | «Аварийная помощь», `/emergency` | сайт, симптом, есть ли доступы. Карточка помечается **СРОЧНО**, клиент получает 4 шага «пока ждёте» |
| 🛠 Сопровождение | тарифы, `/support`, дежурная смена, скидка первым клиентам | что сопровождаем, сайт, серверы, нужен ли CI/CD. В конце бот рекомендует тариф |
| 🧱 Порядок / CI/CD / переезд | «Порядок», `/devops`, `/migration` | задача (подставляется по кнопке), сайт, размер команды, хостинг |
| 🤝 Веб-студиям | `/partners` | сколько проектов, формат партнёрства, сайт студии |
| 💬 Вопрос | шапка, «Задать вопрос инженеру», команда, блог, 404 | вопрос текстом, сайт |

Во всех воронках последним идёт вопрос о связи («пишите в Telegram» или «позвоните мне» с кнопкой «Отправить номер»), затем проверка ответов и согласие на обработку персональных данных со ссылкой на политику.

**Напоминания.** Если клиент бросил заявку на середине, бот напомнит через 1 час и через 24 часа. В аварийной воронке первое напоминание приходит через 10 минут. Под каждым напоминанием есть кнопка «Не сейчас»: после неё бот больше не пишет.

**Карточка в чате команды** содержит ответы клиента, ссылку на его профиль, метку и место кнопки на сайте. Кнопки статусов: «Беру», «Связались», «Не целевая». Если ответить на карточку, бот перешлёт ответ клиенту и сам отметит заявку «в работе».

**Где что менять:**
- цены и тексты о тарифах — `src/data/site.ts`; после `npm run build` они попадают в `app/site_data.json`;
- вопросы и тексты воронок — `app/funnels.py`.

## Запуск на VPS

Подойдёт любой VPS с 1 ядром и 1 ГБ памяти на Ubuntu 22.04 или 24.04.

### 1. Telegram

1. В @BotFather убедитесь, что у бота `@rootlab_help_bot` есть токен (`/mybots` → бот → API Token). **Токен никому не пересылайте**, он вписывается только в файл `.env` на сервере.
2. Создайте группу команды, например «RootLab — заявки», и добавьте в неё бота.
3. Сделайте бота администратором группы. Права не нужны, но так он надёжно видит ответы.

### 2. DNS

У регистратора домена `root-lab.ru` добавьте запись:

```
api.root-lab.ru.  A  <IP вашего VPS>
```

### 3. Сервер

```bash
curl -fsSL https://get.docker.com | sh
```

```bash
git clone https://github.com/rdn513/rootlab-site.git /opt/rootlab && cd /opt/rootlab/bot
```

```bash
cp .env.example .env && nano .env
```

В `.env` впишите `BOT_TOKEN`. `TEAM_CHAT_ID` пока оставьте пустым.

```bash
docker compose up -d --build
```

Напишите `/chatid` в группе команды. Бот ответит её ID, например `-1001234567890`. Впишите его в `TEAM_CHAT_ID` и перезапустите бота:

```bash
docker compose up -d
```

Откройте порты 80 и 443, если включён файрвол:

```bash
ufw allow 80,443/tcp
```

### 4. Проверка

1. Откройте https://api.root-lab.ru/health. Должно вернуться `{"ok": true}`, HTTPS выдаётся автоматически.
2. Откройте https://t.me/rootlab_help_bot?start=site_hero и пройдите воронку. Карточка должна прийти в группу.
3. Ответьте на карточку через «Ответить», и ответ придёт вам в личку бота.
4. Отправьте форму на сайте. Карточка «Заявка с формы сайта» должна прийти в группу.
5. Напишите `/stats` в группе.

### Обновление

```bash
cd /opt/rootlab && git pull && cd bot && docker compose up -d --build
```

### Логи и данные

- Логи: `docker compose logs -f bot`.
- Заявки и сессии хранятся в SQLite, в томе `bot-data` (`/data/bot.sqlite3` внутри контейнера).
- Резервная копия:

```bash
docker compose cp bot:/data/bot.sqlite3 ./backup-$(date +%F).sqlite3
```

```bash
python -m venv .venv && . .venv/bin/activate && pip install -r requirements-dev.txt
```

```bash
pytest
```

Тесты прогоняют воронки целиком на имитации Telegram API, без сети. Они проверяют, что у каждой кнопки сайта есть воронка, что карточки собираются правильно, что переписка идёт в обе стороны и что форма проходит проверку и CORS.
