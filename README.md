# Сайт RootLab

Статический сайт на [Astro](https://astro.build). На выходе получается папка `dist/` с HTML, CSS и минимумом JS. Сайт не обращается к внешним CDN, шрифты IBM Plex лежат в сборке.

## Запуск локально

Нужен Node.js 20 или новее.

```bash
npm install
```

```bash
npm run dev
```

Откройте http://localhost:4321. Страницы обновляются сами при правке файлов.

> В режиме `dev` неразрывные пробелы не расставляются: это делает типограф при сборке. Чтобы увидеть финальный вид, запустите `npm run build`, затем `npm run preview`.

## Сборка

```bash
npm run build
```

Команда делает три вещи:

1. собирает сайт в `dist/`;
2. расставляет неразрывные пробелы: «12 000 ₽», «в договоре», «— » (`scripts/typograph-integration.mjs`);
3. проверяет, что на сайте нет запрещённых формулировок: чужой телефон, «24/7», «15 минут», «2011», «защита информации» и т. д. (`scripts/check-content.mjs`). Если что-то найдено, сборка падает.

Дополнительная проверка: JSON-LD, метки бота, согласие в формах и список всех заглушек.

```bash
node scripts/verify.mjs
```

## Выкладка на хостинг

Загрузите **содержимое** папки `dist/` в корень сайта (`public_html`, `www` и т. п.) по FTP/SFTP или через панель хостинга.

- **Apache** (Beget, Timeweb, Reg.ru): файл `.htaccess` уже лежит в `dist/`. Он подключает страницу 404, кеширование и сжатие.
- **nginx**: минимальный конфиг:

```nginx
server {
  server_name root-lab.ru;
  root /var/www/root-lab/dist;
  error_page 404 /404.html;
  location / { try_files $uri $uri/ =404; }
  location /_astro/ { expires 1y; add_header Cache-Control "public, immutable"; }
  gzip on; gzip_types text/css application/javascript image/svg+xml application/xml;
}
```

После выкладки отправьте `https://root-lab.ru/sitemap-index.xml` в Яндекс Вебмастер.

## Где что менять

| Что | Где |
| --- | --- |
| Цены, тарифы, сроки реакции, контакты, реквизиты, соцсети, команда, частые вопросы главной, метки бота, Метрика, адрес обработчика формы | **`src/data/site.ts`**, один файл |
| Тексты блоков главной | `src/pages/index.astro` |
| Тексты внутренних страниц | `src/pages/<страница>/index.astro` |
| Цвета, шрифты, отступы | `src/styles/global.css`, переменные в `:root` |
| Разметка schema.org | `src/lib/schema.ts`, берёт данные из `site.ts` |

Цены пишутся числом (`35000`), пробелы и «₽» сайт расставит сам. Текст в квадратных скобках вида `[ИНН — уточнить]` — заглушка, на сайте она подсвечена жёлтым.

### Кнопки и Telegram-бот

У каждой кнопки своя метка `?start=…`. Список меток — `botTags` в `site.ts`. При клике отправляется цель Метрики `bot_<метка>`, например `bot_site_hero`.

### Форма заявки

Сейчас форма работает в демо-режиме: показывает «Заявка принята» и пишет данные в консоль браузера. Чтобы заявки начали приходить:

1. Если хостинг с PHP, откройте `public/api/lead.php` и впишите токен бота и `chat_id` (или задайте переменные окружения `RL_TG_TOKEN` и `RL_TG_CHAT`).
2. В `site.ts` поставьте `leadForm.endpoint = '/api/lead.php'`.
3. Пересоберите сайт.

Можно указать и любой другой адрес, который принимает POST с JSON. После успешной отправки срабатывает цель Метрики `form_submit`.

### Яндекс Метрика

Впишите номер счётчика в `analytics.metrikaId`. По умолчанию счётчик загружается только после согласия в баннере cookie (`requireConsent: true`). Если юрист подтвердит, что согласие не нужно, поставьте `false`, и баннер исчезнет.

Цели, которые нужно завести в Метрике (тип «JavaScript-событие»):

- `form_submit`;
- `bot_site_hero`, `bot_site_pricing_audit` и остальные метки из `botTags` с префиксом `bot_`.

### Блог

Статьи — файлы `.md` в `src/content/blog/`. Шаблон: `primer-stati.md`. У него стоит `draft: true`, поэтому на сайт он не попадает. Скопируйте файл, поменяйте заголовок, описание и дату, уберите `draft`. Статья появится по адресу `/blog/<имя-файла>/`, в списке блога и в sitemap.

### Картинки

- `public/og.png` (1200×630) — превью для соцсетей.
- `public/icon-512.png` и `public/favicon.svg` — иконки.
- Фото команды положите в `public/team/` и укажите путь в `team[].photo` в `site.ts`.

## Структура

```
src/
  data/site.ts          ← все цены, контакты, ссылки
  pages/                ← страницы (адрес = путь к папке)
  components/           ← блоки: тарифы, форма, FAQ, команда…
  layouts/Base.astro    ← <head>, SEO, Open Graph, schema.org, баннер cookie
  scripts/              ← аналитика и отправка формы
  content/blog/         ← статьи блога
public/                 ← копируется в dist как есть (robots.txt, .htaccess, api/lead.php)
scripts/                ← типограф и проверки сборки
```
